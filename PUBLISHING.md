# Publishing Workflow

## 1. Markdown is the master
Treat the `.md` files as the source of truth. This keeps the content portable.

## 2. Website
The included `_config.yml` provides a simple starting point for a Jekyll/GitHub Pages site. Keep private material out of a public repository.

## 3. Word
When the manuscript matures, combine the selected chapters and convert the Markdown manuscript to `.docx` using a document conversion workflow such as Pandoc. Apply final book styles in Word.

## 4. PDF
Create the print-ready PDF from the edited Word/book layout, after checking image resolution, page breaks, captions, margins, fonts and front/back matter.

## 5. Printed book
Use the PDF with your selected printer/book service. Keep the Markdown repository as the permanent editable archive.

## Media guidance
- Photos: keep web-sized copies in the site; preserve full-resolution originals separately for the printed book.
- Video: link/embed from an external host rather than committing large video files.
- Scans: keep important letters/certificates/documents in the private archive; publish selectively.
- Privacy: maintain a private master repository and publish only a curated subset.
