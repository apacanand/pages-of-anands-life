# Pages of My Life

A living digital memoir by Anand Natarajan.

This repository is the master source for a memoir designed to evolve over time:

**Markdown -> Website -> Word/PDF -> Printed Book**

## Start here

1. Open `START-HERE.md`.
2. Copy `templates/memory-template.md` whenever you want to add a new memory.
3. Add photographs under `assets/images/`.
4. Keep large videos outside GitHub (OneDrive, YouTube, etc.) and link/embed them.
5. Commit changes regularly so the history of the memoir is preserved.

## Suggested publishing model

- **Private repository:** master archive, drafts, family material, originals.
- **Published website:** selected stories you are comfortable sharing.
- **Book:** export selected Markdown chapters to Word/PDF when ready.
