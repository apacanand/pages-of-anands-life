# Start Here

Don't try to write your life from birth to today in one sitting. Start with memories.

## Your first 10 memories

Write whichever feels easiest first:

1. The earliest thing I can remember
2. The home I grew up in
3. My parents and what I learned from them
4. A school-day memory I still remember clearly
5. Friends who shaped my early years
6. How I met my wife and our journey together
7. Becoming a father
8. A memory with Arnaav I never want to forget
9. A memory with Advik I never want to forget
10. A career moment that changed my direction

Each memory can initially be only 200-500 words. Photographs, dates and details can be added later.
